## Codebase Patterns
- Use ES6 module imports/exports - all JS files are modules loaded via `<script type="module">`
- Three.js r160 loaded via import maps in index.html, import as `import * as THREE from 'three'`
- Three.js addons (EffectComposer, passes, etc.) imported from `three/addons/` path
- Constants defined in js/core/constants.js - use these for all magic numbers
- Content data (work history, skills, etc.) lives in js/data/content.js
- HTML validation: all buttons need `type="button"`, headings need content
- Use `let` for module-level exports that need reassignment in init functions
